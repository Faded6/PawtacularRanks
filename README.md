## 🌟 Features (UI / UX Pro Max)

- 🎨 **Sleek Dark Cyber-Pet Aesthetic**: Luxury dark surfaces (`#090a0f`), vibrant amber/honey accents (`#f59e0b`), glassmorphism cards, and fluid glowing badges.
- 🎬 **Interactive YouTube Shorts Showcase**: Filter by dogs, wild & farm, primates, otters, and birds with custom play overlays.
- 📱 **Embedded Modal Player**: Watch Shorts instantly without leaving the website.
- ⏱️ **Interactive Rank Countdown Simulator**: Step through Rank #5 to Rank #1 with dynamic sound effects and confetti celebration upon revealing #1!
- 👑 **Daily Community Poll**: Real-time voting for today's funniest animal with live percentage calculation, sound, confetti, and `localStorage` persistence.
- 🔊 **Pawtacular Soundboard**: 6 comedy sound effects (Bark, Meow, Quack, Spring Boing, Fail Wah-Wah, Fanfare) synthesized locally using the Web Audio API (zero external audio lag).
- 📩 **Submit Your Pet Portal**: Interactive clip submission form with instant `mailto` drafting to `pawtacularranks@gmail.com`.
- 🛡️ **Creator & Fair Use Policy**: Transparent licensing and attribution commitment for original clip owners.
- ⚡ **Blazing Fast**: Vite + React 19 + Tailwind CSS v4, builds in <400ms.

## 🔗 Custom Free Domain Setup (via FreeDomain)

You can connect a free domain from [DigitalPlatDev/FreeDomain](https://github.com/DigitalPlatDev/FreeDomain.git) (such as `.dpdns.org`, `.us.kg`, `.qzz.io`, or `.xx.kg`):

1. **Register your free domain** on [FreeDomain](https://github.com/DigitalPlatDev/FreeDomain.git).
2. **Add Domain in Vercel**:
   - Go to your Vercel Project Settings > **Domains**.
   - Enter your registered free domain (e.g., `pawtacular.dpdns.org`).
3. **Configure DNS Records**:
   - Add a `CNAME` record pointing your subdomain to:
     ```text
     cname.vercel-dns.com
     ```
4. Vercel will automatically issue and renew a free SSL certificate within minutes!
